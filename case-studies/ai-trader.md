# AI.Trader oktatási és AI mentor platform

[← Vissza a projektmenühöz](../README.md#project-menu)

## Mit tartalmaz?

- szerepkörös hitelesítés és védett felhasználói felület;
- oktatási modulok, vizsgák és haladási állapotok;
- szerveroldali végpontok és adatmodell;
- AI mentor koncepció és felhasználói folyamatok;
- Telegram Bot API integráció;
- automatizált heti piackutatási workflow;
- reszponzív, egységes alkalmazás-shell.

## Saját szerepem

A termék frontendjét, backendjét, adatmodelljét, hozzáférési logikáját, integrációs irányait és vizuális rendszerét egy összefüggő platformként építettem fel és teszteltem.

**Technológia:** HTML · CSS · JavaScript · Supabase · Cloudflare Workers · Telegram Bot API
